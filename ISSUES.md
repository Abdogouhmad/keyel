## How to log one

1. Add a row with the date, severity, the screen/area and a one-line summary.
2. Put the exact steps under **Repro** (or link a longer note in `docs/`).
3. Attach a diagnostics file from **Settings → Report a problem** when relevant
   — it is redacted (versions, device, non-secret settings only).
4. Fix S1/S2 before S3; move the row to **Fixed** with the commit hash.
